Where the files go

  1. Save boot0.rom and boot1.rom.
  2. Copy both into games/NGage/ on the MiSTer's SD card, next to boot0.vhd.
  3. Start NGage from the Console menu.

The core's README has the whole setup.

The firmware archive

It holds Nokia's service packages for the N-Gage QD (model RH-29). The firmware is Nokia's and is not part of this page or of the core.

To find it, search the Internet Archive for Nokia DCT4 firmwares. From that collection's file list, download N-GageQD RH-29.zip (811,528,203 bytes) and drop it here as it is. The page takes the package for firmware 4.10, the version the core runs, out of it.

A smaller download

In the same file list, the zip's View Contents link shows the packages inside, and one of them downloads from there by itself. Drop that instead of the zip. Take this one, which is also the one the page picks from the zip: of the others named for 4.10 only RH-29_dp_apac_v_3_0_MCUSW4_10.exe has the firmware as well, with the language packs of Asia and the Pacific.

Where the files go

  1. Save boot0.rom and boot1.rom.
  2. Copy both into games/NGage/ on the MiSTer's SD card, next to boot0.vhd.
  3. Start NGage from the Console menu.

The core's README has the whole setup.

The data package

It is Nokia's service installer for the N-Gage QD (model RH-29) with firmware 4.60, the version the core runs. The firmware is Nokia's and is not part of this page or of the core.

To find it, search the Internet Archive for Nokia DCT4 firmwares. In that collection's file list, N-GageQD RH-29.zip has a View Contents link, and the package downloads from there by itself.

If you already have RH2946.0C1 and RH2946.0S5, drop those instead: they are the same two files under Nokia's names.

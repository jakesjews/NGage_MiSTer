# ARM9V2 session 10 — completion and request boundaries

Work starts at `efe6811` (RTL `12bb290`), on `codex/arm9v2`. ZAP remains
the default. The two-clock late pickup, retained scalar misses, RF retiming
bound, and raw hit windows 3/4/5 are acceptance constraints, not tradeoffs in
this session. All Quartus work runs on Ubuntu, seed 2, 104 MHz, with at most
two of this session's containers and four globally. No LogicLock is used.

The Codex and Antigravity timing consults on master were read first. The
Codex reading of the actual paths is the relevant distinction: W's
`load_writer` paths reach cache metadata and collision capture **through the
late bypass and A's address adder**. They are not evidence that registering
a store enable alone removes those paths. Likewise, FCSE never changes the
cache index bits; expressing that explicitly is not itself a measured gain.

## Measurement contract

Every retained RTL cut must preserve all 267 cycle/instruction pairs in
ZAP and both V2 predictor configurations, 69 QEMU comparisons per
configuration, and all 85 timing windows at 0:0, 0:3, and 2:9 in both V2
modes. Existing test binaries and QEMU references are reused. Both stripped
and debug emu configurations are linted with each CPU selection, and the
committed generated netlist must pass `make cpu-gen-check`.

The settings comparison fits the same S9 netlist with the old QSF and with
`PLACEMENT_EFFORT_MULTIPLIER 2.0` and
`ROUTER_TIMING_OPTIMIZATION_LEVEL MAXIMUM`, matching NGage.qsf. Subsequent
fits use those new settings. The trial script permits a separate
`TRIAL_OUT` directory so two server jobs cannot overwrite local artifacts.
The timing report requests independent endpoint-family reports in addition
to the global worst thirty; a family hidden below thirty similar paths is
still measured. Neither reporting nor local output isolation changes RTL.
